系统设置

这些是 dshup 客户端行为，不是官方 dsh 网页设置
开机自动启动
登录系统后自动在后台启动 DeepSeek Harness（打开客户端时无需等待）
关闭客户端时停止 dsh 服务
关闭窗口时停止由本客户端启动的 dsh 后台服务（原本就在运行的服务不受影响）
关闭窗口时最小化到托盘
点关闭按钮时隐藏到系统托盘，而不是退出客户端
启动后最小化
打开客户端后自动最小化到任务栏
任务完成时发送系统通知
会话任务结束后弹出桌面通知
硬件加速
GPU 加速渲染。关闭可省内存，部分显卡可修复花屏。修改后需重启客户端
启动时检查更新
静默查询 GitHub Releases，发现新版本只写日志不弹窗
下载镜像
安装 Node / pnpm / dsh 时使用的 npm 与 Node 二进制源
网络模式
依赖下载是否走系统代理。本地 3080 检测始终直连
